# Security policy

*Version française plus bas.*

## Supported versions

AuroDownloader is before its version 1. Only the latest published release receives security
fixes; please check that a problem is still there in it.

## Reporting a vulnerability

Please report vulnerabilities **privately**, through GitHub's
[security advisories](https://github.com/auriciel21/AuroDownloader/security/advisories/new)
(“Report a vulnerability”), **not** in public issues, discussions or pull requests.

Useful details: the version (Options, About), the system, the part concerned (engine, desktop
application, Android, browser extension, remote interface, plugins), the steps to reproduce it
and what an attacker gains. Please do not include personal data or real credentials.

The report stays private until a fix is published; you will be credited in the advisory if you
wish.

## Scope and design

The security review of the remote interface, the plugins and the local channel, with its
threat model and the risks that remain, is in [`docs/SECURITE.md`](docs/SECURITE.md) (in
French).

# Politique de sécurité

## Versions suivies

AuroDownloader n'en est pas encore à sa version 1. Seule la dernière version publiée reçoit les
corrections de sécurité : merci de vérifier que le problème s'y trouve encore.

## Signaler une faille

Merci de signaler les failles **en privé**, par les
[avis de sécurité](https://github.com/auriciel21/AuroDownloader/security/advisories/new) de
GitHub (« Report a vulnerability »), et **non** dans les tickets, discussions ou demandes de
fusion publics.

Utile au signalement : la version (Options, À propos), le système, la partie concernée (moteur,
application de bureau, Android, extension du navigateur, interface distante, plugins), la façon
de reproduire le problème et ce qu'un attaquant y gagne. Merci de n'y mettre ni données
personnelles ni vrais identifiants.

Le signalement reste privé jusqu'à la publication d'une correction ; vous serez cité dans l'avis
si vous le souhaitez.

## Périmètre et conception

La revue de sécurité de l'interface distante, des plugins et du canal local, avec son modèle de
menace et les risques qui restent, est dans [`docs/SECURITE.md`](docs/SECURITE.md).
