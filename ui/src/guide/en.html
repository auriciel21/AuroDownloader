AuroDownloader user guide

AuroDownloader is a free and open source download manager for Windows, Linux and Android. It downloads fast, in several parts at once, and picks up where it left off after an interruption, without losing or corrupting data.

A single engine does all the downloading; the desktop application, the Android application, the browser extension, the web interface and the command line only drive it. Closing the window therefore does not stop downloads.

Installation

Packages are on the project's Releases (https://github.com/auriciel21/AuroDownloader/releases) page. Each release also provides SHA256SUMS, the checksum of every file, to check a download.

Windows 10 and 11

  1. Download AuroDownloader_<version>_x64-setup.exe (most computers) or _arm64-setup.exe (computers with an ARM processor).
  2. Run it. It installs for your account only, without administrator rights, in %LOCALAPPDATA%\AuroDownloader. If WebView2 is missing (rare on Windows 11), the installer downloads it.
  3. If Windows shows "Windows protected your PC" and "unknown publisher", the installer is not signed. Choose "More info", then "Run anyway", if you did get it from the Releases page.

The installer also registers the extension's relay with the browsers.

Linux

WebKitGTK 4.1 is required: Ubuntu 22.04, Debian 12 or later.

  • .deb package (Debian, Ubuntu and derivatives):
sudo apt install ./AuroDownloader_<version>_amd64.deb

(_arm64.deb on an ARM computer). It registers the extension's relay with the browsers and installs the manual pages (man auro).

  • AppImage: make the file executable (chmod +x AuroDownloader_<version>_amd64.AppImage) and run it. The AppImage updates itself, with your consent; it does not register the extension's relay.

Android 8 and later

Download AuroDownloader_<version>_arm64.apk on the device and open it. Android asks you to allow installing from that source (the browser or the file manager). See Android.

Browser extension

See Browser extension.

Updates

The desktop application looks for updates at most once a day and offers a new version; nothing is installed without your consent (Options, General, "Updates"). The .deb package only tells you, with a link to the release page: install the new package like the first one. On Android, install the new APK over the old one.

Uninstalling

  • Windows: Settings, Apps, AuroDownloader, Uninstall. Your downloaded files are never touched. The download list, the history and the preferences are kept, unless you tick "delete the data": it also deletes the logs, the plugins, the video tools, the remote access certificate, and the cookies and passwords kept in the Windows vault.
  • Linux: sudo apt remove auro-downloader for the .deb; simply delete the AppImage file.
  • Android: like any application. Files already downloaded stay in Download/AuroDownloader.

First steps

The window

  • Toolbar, at the top: Add, Video, Links, Resume, Stop, Resume all, Stop all, Delete, Clear finished, Properties, Schedule, History, Options.
  • Categories, on the left: All downloads, Unfinished, Finished, each with its file types (Archives, Documents, Images, Music, Programs, Videos, Other), then the queues. The number of downloads is next to each category.
  • Table, in the middle: File name, Size, Progress, Status, Time left, Speed, Added. Clicking a column header sorts the table.
  • Status bar, at the bottom: what is going on, and the global speed limit.

On first launch, AuroDownloader tells you it looks for updates at most once a day; "Don't check" turns that off.

A first download

  1. Copy the address of a file, for example https://deb.debian.org/debian/README.
  2. "Add" (or Ctrl+N), paste the address into "Addresses or magnet links, one per line".
  3. "Save to" shows the folder: by default, your Downloads folder; "Browse…" picks another one.
  4. "Start". The download appears in the table, with its progress.

"Download later" adds it paused: "Resume" will start it.

What you can do with a download

Select a row (several with Ctrl or Shift), then use the toolbar, or right-click for the menu: Open, Show in folder, Download again…, Move/Rename…, Refresh address…, Resume, Stop, Limit speed…, Delete…, Properties.

  • Stop pauses; Resume carries on where it stopped.
  • Delete… removes it from the list; for a finished download, the "Also delete finished files from the disk" box deletes the file too.
  • Clear finished removes completed and cancelled downloads from the list; their files stay on disk, and the history keeps them.
  • A double click, or Enter, opens the Properties.

A finished file opens with the system's program; for safety, AuroDownloader never opens a program or an installation package: "Show in folder" shows it.

Closing the window

Closing the window keeps the application in the notification area (next to the clock): downloads go on. The notification area icon reopens the window, or quits: "Quit (downloads continue)" or "Quit and stop downloads". This is set in the Options.

When the computer restarts, unfinished downloads resume when AuroDownloader starts again; "Start with the session" does that by itself.

Downloads

Adding

The "Add downloads" box takes:

  • addresses http://, https://, ftp://, ftps:// or sftp://, one per line (several at once);
  • magnet links (see Torrents);
  • .torrent or Metalink files ("Choose .torrent or Metalink files…", or dropped on the window).

Optional fields:

  • Mirrors, one per line: other addresses of the same file. Each one is checked (same size, same bytes) before use, and the download is spread between them by speed; a failing mirror is set aside.
  • Expected checksum: SHA-256, SHA-1 or MD5 (sha256:… or the value alone). The file only takes its name once checked; otherwise the download fails with "the file does not match its expected checksum" and the file keeps its temporary name.
  • Save to: the folder.

If the address is refused, the box stays open and says why, with the cursor in the field concerned.

A page of a file host supported by a plugin is read by that plugin; "Add these pages as they are, without a plugin" avoids it.

Statuses

Queued (queue full, or time slot closed), Downloading, Paused, Retrying soon (network or server outage: AuroDownloader retries by itself), Verifying the checksum, Finishing (the command of a rule is running), Completed, Failed (the reason is given), Cancelled, Seeding (torrent).

A full disk pauses the download ("disk full"): it starts again by itself once there is room.

Properties

Double click on a row, Enter, or "Properties":

  • file, folder, address, source page, status, size, downloaded, speed, time left;
  • Connections: the number of connections of this download (automatic by default);
  • Can resume: whether the server allows resuming;
  • Checksum: the expected one, or the one found next to the file, and whether it was checked; it can be given, changed or cleared here until the download is finished;
  • Mirrors: each source, its state and speed; "Add a mirror";
  • a segment map: what has been received, part by part;
  • the speed limit of this download.

FTP, FTPS and SFTP

  • Unencrypted FTP never sends a password, unless you allow it for that site ("FTP: allow without encryption", in the site logins).
  • SFTP: on first contact, AuroDownloader shows the server key fingerprint, in the Properties ("SSH server key", "Accept the key…"). Check it with the server's administrator before accepting it; downloads from that server then resume. A key that changes blocks the downloads: it may be an attack.
  • Logins: name and password, or an SSH private key, in the site logins. An address like ftp://name:password@server/file works too: the password is stored in the system vault and removed from the address.

Sites that need an account

A site's login (Basic or Digest) is set in the site logins. Passwords are kept in the system vault (Windows Credential Manager, Linux keyring), never in AuroDownloader's database. For a site where you sign in through a page, use the extension, which passes the cookies on.

Metalink

A .meta4 or .metalink file, or its address, gives each file's addresses and checksum. If it holds several files, the box lets you tick them. Every faulty piece is downloaded again, preferably from another source; a source that gives two faulty pieces is set aside.

Moving, renaming, refreshing, downloading again

  • Move/Rename…: another name or another folder, even on another disk; possible for a download that is not running, finished or not.
  • Refresh address…: replaces an expired link. For a started download, the new address must give the same file; what was received is kept.
  • Download again…: starts over. "Replace the file already downloaded" overwrites it; otherwise the new one gets another name.

Where files go

While downloading, the file has a temporary .part name; it takes its name at the end. A name already in use gets a suffix (file (1).iso). Filing rules can choose the folder and the name.

Torrents

Adding a torrent

  • Paste a magnet link (magnet:?…) into "Add";
  • or choose a .torrent file ("Choose .torrent or Metalink files…"), or drop it on the window;
  • or open it with AuroDownloader from the browser or the file manager: it fills in the "Add" box, which you confirm. Associating magnet links and .torrent files with AuroDownloader is an option, off by default (Options, BitTorrent).

A torrent needs no checksum: it checks its pieces itself.

Choosing the files

A torrent's Properties show its files: untick the ones you do not want, then apply. The others are not downloaded.

Seeding

A finished torrent stays Seeding: it sends what it received to other peers, up to the chosen limit (Options, BitTorrent, "After downloading, seed"):

  • Do not seed;
  • Until as much is sent as received (ratio 1), the default;
  • up to another ratio;
  • No limit, until I stop it.

Seeding does not take a place in the queue: other downloads start meanwhile. On a metered network (Android), nothing is seeded.

Settings (Options, BitTorrent)

  • Upload limit: the upload speed to other peers.
  • Network interface for torrents (VPN): torrents only go through that interface; if it disappears (VPN off), they stop and wait for it to come back. Other downloads are not affected.
  • Open the listening port on the router (UPnP): more reachable peers, off by default.

Torrents never go through the proxy.

When resuming

After a restart, AuroDownloader checks the pieces already received again before resuming: it takes longer than an instant resume, but nothing faulty is kept.

Videos

On Windows and Linux, AuroDownloader downloads the video of a web page, through two free programs: yt-dlp (which reads the page) and ffmpeg (which joins picture and sound). It does not download protected videos (DRM).

Installing the tools

The first time, the "Add a video" box ("Video" button) offers "Install yt-dlp and ffmpeg": they are downloaded from their official releases, their checksum or signature is checked, and they take about 400 MB. Nothing is installed without that click.

yt-dlp updates itself, at most once a day (Options, Video, "Let yt-dlp update itself"), since sites change often.

Downloading a video

  1. "Video", paste the address of the page, "Analyse".
  2. AuroDownloader shows the title, the duration, the site and the available qualities, with their size. Choose the quality (or "All formats" for a precise choice) and the container (automatic by default).
  3. Subtitles: tick the languages you want; they are kept next to the video, in the site's format. A missing language is reported at the end.
  4. "Start" or "Download later".

The video goes through the same queues, speed limits and time slots as other downloads, and resumes the same way after an interruption.

From the browser, the extension does the same in one click.

Link grabber

Every file of a page

  1. "Links" opens "Analyse links".
  2. Paste the address of a web page, or a text containing addresses, then "Analyse"; or "Import a list (text, CSV)…".
  3. AuroDownloader reads the page (without running JavaScript) and lists the file links, with their name, size and address. Sizes are asked from the servers, four at a time.
  4. Filters: extensions (iso, zip), minimum and maximum size, regular expression on the address. "Also show pages and links without an extension" shows the rest.
  5. Tick ("Check all", "Uncheck all"), choose the folder, then "Download".

Each link becomes a download; a refused link does not stop the others.

Copied links

Option "Offer to add copied links" (Options, General, off by default): when you copy the address of a file or a magnet link, a system notification offers it; a click opens "Add". The clipboard is only read for that, and nothing from it is kept. If AuroDownloader's notifications are turned off in the system, the Options say so.

Organising

Queues

Every download is in a queue. The main queue exists from the start; it runs 3 downloads at a time, the others wait ("Queued"). Other queues are created from the command line, with their number of simultaneous downloads and their own speed limit:

auro queue create Night --max-active 2 --limit 2M
auro add <address> --queue Night

Queues appear under "Queues", in the categories.

Speed limits

  • Global: at the bottom of the window, "Global speed limit", or Options, Connection.
  • Of one download: menu "Limit speed…", or its Properties.
  • Of a queue: from the command line (auro limit 1M --queue Night).

A changed limit applies at once, to running downloads too.

Schedule

"Schedule" sets, for a queue:

  • Download only during these time slots: days and hours ("Add a time slot"), for example Monday to Friday from 23:00 to 07:00. Outside the slots, the queue waits ("Paused (schedule)") and starts again by itself when a slot opens.
  • When the queue has nothing left to download: Do nothing, Put the computer to sleep or Shut down the computer. The action is announced a minute before, with a button to cancel it.

Filing rules

Options, Rules. A rule files the downloads added without a chosen folder (by the extension, copied links, the remote interface):

  • If: file types or extensions, site domains, regular expression on the address or the file name (all criteria met; empty: any task).
  • Then:
    • a folder: full path, or relative to the download folder (Videos/Talks), created if missing;
    • a file name, a template with {name} (without the extension), {ext}, {host} and {date} (day added): for example {date} {name}.{ext};
    • a command when the download ends: a program (full path), its arguments, one per line, and a time limit. Variables: {path} (the file), {dir}, {name}, {size}, {sha256}, {id}. For example, an antivirus with {path}. The command never goes through a shell; the download stays "Finishing" while it runs, then fails if it fails or runs past its time limit ("Resume" runs it again).

The first enabled rule that matches applies; "Move up" and "Move down" change the order. A torrent only takes the folder. Rules can only be changed in the application on the computer (not from the remote interface).

History

"History" lists finished downloads, even those removed from the list: search by name, folder or site, "Export as CSV…", "Clear history…".

Options

"Options" opens the settings, in sections. The left and right arrow keys move from one section to the next.

General

  • Language: the system's, English or French.
  • Start with the session, in the notification area.
  • Closing the window keeps the app in the notification area: otherwise, closing the window quits the application (downloads go on, through the engine).
  • Bring the window to the front when a download is added (by the browser or the command line).
  • Offer to add copied links: see Link grabber.
  • Updates: "Check for updates" (at most once a day, from GitHub, which sees the IP address and the version in use, nothing else) and "Check now". A new version shows up in "New version", with what is new: "Install and restart" (Windows, AppImage), "Open the release page" (.deb package), or "Later". The update is checked by its signature; nothing is installed without your consent. During the installation, the application closes, then restarts, and downloads resume.

Saving

  • Folder for new downloads, when none is chosen (extension, copied links, remote interface).
  • Reserve each file's space from the start: a full disk shows at once, and the file is less fragmented.
  • Look for the checksum next to the file (SHA256SUMS, .sha256…): when you give none, AuroDownloader looks for the checksum published next to the file, and checks it.

Rules

The filing rules: New…, Edit…, Move up, Move down, Disable, Delete.

Connection

  • Global speed limit.
  • Proxy: the system's (default), none (always direct), or "This one": address (http://, https:// or socks5://), addresses to reach directly, login and password (stored in the system vault). Torrents never go through the proxy; the update check uses the system's.

BitTorrent

Seeding, upload limit, network interface (VPN), UPnP, association of magnet links and .torrent files: see Torrents.

Video

Installing yt-dlp and ffmpeg, and updating them: see Videos.

Site logins

  • A site's logins (New…, Edit…, Delete): site, user name, password or SSH private key (SFTP), "FTP: allow without encryption". Passwords go to the system vault and never come out.
  • Accepted SSH server keys, with their fingerprint; "Forget the key".

Plugins

A host plugin turns the page of a file host into direct links.

  • "Install a plugin…": choose a .wasm file. Before installing, AuroDownloader shows its name, its author, the pages it handles, the domains it will contact and its fingerprint: only install plugins you trust.
  • A plugin runs isolated: it sees neither your files, nor your passwords, nor your cookies, and only contacts its declared domains.
  • Disable, Remove. A new version that asks for more domains asks for your consent again.

Remote access

See Remote access.

About

  • AuroDownloader's version.
  • Log detail: Errors only, Errors and warnings, Normal (recommended), Detailed, for troubleshooting.
  • Export a diagnostic…: see Troubleshooting.
  • Quit and stop downloads.

Browser extension

The extension hands the browser's downloads, magnet links and the page's video to AuroDownloader. It works with Firefox (128 and later), Chrome (121 and later) and Edge, with the desktop application installed (it goes through its relay, auro-relay).

Installing

The extension is not yet in the browser stores; it is loaded from the project's extension folder:

  • Chrome: chrome://extensions, "Developer mode", "Load unpacked", extension folder.
  • Edge: edge://extensions, "Developer mode", "Load unpacked". Edge reports a warning about background.scripts (for Firefox): it has no effect.
  • Firefox: about:debugging#/runtime/this-firefox, "Load Temporary Add-on…", file extension/manifest.json (to load again at each Firefox start). Then, in about:addons, AuroDownloader, Permissions: allow access to all sites, otherwise cookies cannot be read.

On Linux, the relay is registered with the browsers only by the .deb package, not by the AppImage.

If IDM or another download manager is installed, disable its extension: otherwise it takes the downloads before AuroDownloader.

What it does

  • Downloads: those over 1 MiB (adjustable) go to AuroDownloader. The browser keeps its own until AuroDownloader has accepted it; the icon shows "✓" or "!".
  • Click with Alt: leaves that download, or that magnet link, to the browser.
  • Magnet links: a click hands them to AuroDownloader (option on by default). Downloaded .torrent files become torrents.
  • Context menu: "Download with AuroDownloader" on a link, an image, a video or a sound; "Download this page's video with AuroDownloader" (best quality).
  • Icon window: the page's video, with the choice of quality, audio only and subtitles, then "Download".

Settings

Icon window, "Settings":

  • Hand downloads to AuroDownloader, only from a given size;
  • Excluded sites (one per line; their subdomains too);
  • In private browsing too (downloads and magnet links of private windows);
  • Send the page's cookies and address: for downloads that require signing in; AuroDownloader keeps the cookies in the system vault;
  • Hand magnet links to AuroDownloader;
  • Link with AuroDownloader, "Check": "Relay found" if all is well.

Android

The Android application holds the same engine as the desktop version: HTTP(S), FTP(S), SFTP and torrent downloads, with the same safe resume. Site videos (yt-dlp) are not available there.

Adding

  • Add, then the address: https://…, ftp://…, sftp://… or a magnet link.
  • Share a link from another application (browser, messaging), or open a magnet link or a .torrent file with AuroDownloader: it is added directly.

Files go to Download/AuroDownloader, where other applications see them.

The list and the details

Tap a download for its details: status, size, speed, time left, checksum; Pause, Resume, Retry, Cancel the download, Remove from the list, Open; for a torrent, the choice of its files; for an unknown SFTP server, its key fingerprint and "Accept the key…".

In the background

A download goes on when the application is closed: a notification shows the progress, with "Pause all". Android may ask to allow notifications on the first download.

Settings

  • Download folder (shown: Download/AuroDownloader) and Global speed limit.
  • Look for the checksum next to the file, Reserve each file's space from the start.
  • Wi-Fi only: downloads only over Wi-Fi (or Ethernet), never over mobile data. A metered Wi-Fi, such as a phone hotspot, counts as Wi-Fi.
  • Resume after the device restarts: unfinished downloads resume, or a notification offers to resume them (Android 14 and later).
  • BitTorrent: seeding after downloading, upload limit. Nothing is seeded on a metered connection.

To go through a VPN, use Android's: it applies to the whole application.

Remote access

The remote web interface shows the AuroDownloader window in a browser, on a phone or another computer on the same network, to add and follow downloads. It is off by default.

Turning it on

Options, Remote access:

  1. Control downloads from another device: tick it.
  2. Listening address and Port: this computer's address on the local network (the list offers them), and the port (7380 for example). Windows may ask to allow AuroDownloader through the firewall.
  3. Away from this computer, the connection is always encrypted (HTTPS). AuroDownloader makes its own certificate; the other device's browser warns the first time: compare the SHA-256 fingerprint shown in the Options before accepting. "Use my certificate…" takes a certificate of yours instead.

Adding a device

"Add a device…": a name ("Phone"), then the permissions:

  • Full control: add, stop, delete;
  • Add only;
  • View only.

"Create the token" shows the page address and a QR code: scan it with the device, which opens the page signed in. The token can also be pasted by hand. It is shown only once; "Remove" a device cuts its access at once.

What the remote page does not do

For safety, it does not choose a folder on the computer (only a subfolder of the download folder), does not open files, does not change the rules, the plugins or the remote access settings, and only downloads from the Internet, not from the computer's local network (unless auro remote allow-private on, from the command line).

Command line

auro drives the same engine as the application: a download added by auro shows up in the window, and the other way round. It is installed with the application (next to it on Windows, in the path on Linux with the .deb package). If the engine is not running, auro starts it.

Every command has its help (auro add --help) and, on Linux, its manual page (man auro, man auro-add, man aurod). The command line's messages and manual pages are in French.

Common commands

auro get https://deb.debian.org/debian/README -o .   # download and follow the progress
auro add <address>… --paused                         # add without waiting (paused)
auro list                                            # list
auro watch                                           # follow what is running
auro pause <id>… ; auro resume <id>…
auro remove <id>… ; auro restart <id>… --delete-files
auro move <id> -o <folder> -n <name>
auro refresh <id> <new-address>

Without -o, auro add downloads to the current folder; --auto lets the filing rules choose.

Going further

auro add <address> --checksum sha256:<hex>          # expected checksum
auro get <address> --mirror <address>…              # mirrors
auro metalink <file.meta4> ; auro get <file.meta4> --select 0,2
auro add file.torrent ; auro files <id> --select 0,2-4
auro links <page> -e iso,zip --min-size 10M --add -o .
auro video info <page> ; auro video get <page> --subs fr,en
auro limit 2M ; auro limit --upload 500K ; auro limit 1M --queue Night
auro schedule set --days 1-5 --from 23:00 --to 07:00 --then sleep
auro login set <site> -u <name> ; auro hostkey list
auro proxy manual socks5://host:1080 -u me ; auro proxy system
auro history [text] [--csv]
auro config ; auro config torrent.ratioLimit 1.5
auro diagnostic --save diag.zip
auro engine stop

Exit codes

auro returns 0 when everything is done, 1 after an error or when part of the request was refused (for instance one file of a Metalink, the others being added), 2 for a mistyped command, and 130 when Ctrl-C stops a follow-up (get then pauses its tasks). A displayed address never shows its password.

The engine alone

aurod is the engine, without a window. For a server or a NAS, it runs on its own, and is used through auro or through remote access.

Troubleshooting

Common problems

What you seeWhat to do
"Retrying soon" that lastsThe network or the server does not answer: AuroDownloader retries by itself. Check the connection and the proxy (Options, Connection).
"refused by the server"The link may have expired: "Refresh address…" with a fresh link, taken from the source page.
The server asks you to sign inSite logins (Options, Site logins), or use the extension, which passes the cookies on.
"certificate rejected"The server's HTTPS certificate is not valid: AuroDownloader does not download without it.
"the file does not match its expected checksum"The file received is not the one announced: check the checksum, or download again.
"disk full"Make room: the download starts again by itself.
"remote file changed"The file changed on the server during the download: "Download again…".
The extension takes nothingIcon window, Settings, "Check"; disable IDM's extension; on Linux, prefer the .deb package.
A video is refusedIt is protected (DRM), or yt-dlp does not know the site yet: wait for it to update itself.
Torrents do not startIf a network interface (VPN) is chosen (Options, BitTorrent), it must be there.

Diagnostic

Options, About, Export a diagnostic…: a summary of the engine's state and its recent logs, cleaned (no addresses, file names, headers or logins), shown before being saved in a .zip archive, to attach to a report. For a problem that happens again, first set "Log detail" to "Detailed, for troubleshooting", reproduce it, then export.

Where the data is

  • The download list, the history and the engine's settings are in a database (auro.db), with the logs (logs): %LOCALAPPDATA%\AuroDownloader on Windows, ~/.local/share/aurodownloader on Linux.
  • Passwords, cookies and tokens are in the system vault, never in the database.

Privacy

AuroDownloader sends no telemetry. It only contacts:

  • the servers of the files you download (and their mirrors);
  • torrent peers;
  • GitHub, at most once a day, for updates (can be turned off);
  • the official releases of yt-dlp and ffmpeg, if you install them;
  • the domains declared by the plugins you install.

Reporting a problem

On the issues (https://github.com/auriciel21/AuroDownloader/issues) page, with the version (Options, About), the system, what happens, and the diagnostic if possible. A security flaw is reported privately, through the security advisories (https://github.com/auriciel21/AuroDownloader/security/advisories/new).
