# Guide de l'utilisateur d'AuroDownloader

AuroDownloader est un gestionnaire de téléchargement libre et gratuit pour Windows, Linux et
Android. Il télécharge vite, en plusieurs morceaux à la fois, et reprend là où il s'était
arrêté après une coupure, sans perdre ni abîmer de données.

Un seul moteur fait tous les téléchargements ; l'application de bureau, l'application
Android, l'extension de navigateur, l'interface web et la ligne de commande ne font que le
piloter. Fermer la fenêtre n'arrête donc pas les téléchargements.
