# AuroDownloader user guide

AuroDownloader is a free and open source download manager for Windows, Linux and Android. It
downloads fast, in several parts at once, and picks up where it left off after an
interruption, without losing or corrupting data.

A single engine does all the downloading; the desktop application, the Android application,
the browser extension, the web interface and the command line only drive it. Closing the
window therefore does not stop downloads.
